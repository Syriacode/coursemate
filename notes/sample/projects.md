# CS 201 Projects

## Project 1: Text statistics

Build a program that reads a text file and reports word counts, the most frequent words, and the number of distinct words. Store the counts in a hash map you implement yourself. Project 1 is due in week 6.

## Project 2: Campus route planner

Model the campus as a graph of buildings and paths, and use breadth-first search to find the route with the fewest segments between two buildings. Project 2 is due in week 13. You may work in pairs; both partners submit the same repository and must list each other in the README.

## Submitting work

Submit through GitHub Classroom: accept the assignment link, push your code to the repository it creates, and the autograder runs on every push. Your grade comes from the last push before the deadline. If the autograder fails, open the log, read the first error, fix it, and push again. If it still fails and you think the autograder is at fault, email the instructor with a link to your repository before the deadline.
